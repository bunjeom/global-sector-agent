# 투자터미널 (global-sector-agent)

한 종목을 **네 가지 관점(기술·실적·가치·거시)** 으로 따로 분석한 뒤 하나의 결론으로 합치는 Streamlit 기반 종목 분석 도구입니다.
미국·한국 상장 종목을 지원하며, 모든 숫자는 공개 데이터에서 받아 계산합니다.

프로젝트 수업에서 시작한 뒤, 혼자 기능을 넓혀 가며 계속 개발하고 있습니다.

> 개인 학습·연구용 프로젝트이며 투자 권유가 아닙니다. 가격으로 검증할 수 있는 규칙(국면 게이트, 기술적 진입 신호)은 백테스트했고 결과를 아래에 그대로 적었습니다. 실적·가치·거시 트랙은 과거 시점 데이터가 없어 검증하지 않았습니다.

## 무엇을 하나

| 트랙 | 질문 | 주요 계산 |
|---|---|---|
| T · 기술 | 지금 사고팔 시점인가 | 7단계 차트 상태, 지지·저항 구간, 셋업별 진입·손절·목표가와 1R 기준 수량 |
| E · 실적 | 이익이 어느 단계에 있나 | 실적 국면 G1~G5, 서프라이즈·리비전, 증분 영업이익률, 이익의 질 5개 점검 |
| V · 가치 | 얼마면 살 만한가 | 자기 PER 밴드(σ)·피어 PER, 국면별 목표 배수, 0~3차 분할 매수선, 시나리오 기대수익률 |
| 거시 | 거시 변수에 얼마나 흔들리나 | 시장 잔차화 회귀(HAC·Huber), 표본 외(OOS) 검증, 13주 수익률 기여 분해 |

종합 탭은 하드 킬 게이트 → V 가격 자격 → T 판정 → 거시 오버레이 순으로 결론을 내고, 8개 종목 유형(ARCH_1~8)과 3줄 요약으로 보여줍니다.

## 매매 틀 (개편 중인 설계 방향)

백테스트에서 가격만 보는 단기 진입 신호는 무작위 진입보다 낫지 않았습니다. 그래서 진입 신호를 따로 찾는 대신, **매수 논리 하나를 '진입 → 논리 무효화(손절) → 매도'까지 한 묶음으로 설계**하는 방향으로 바꾸고 있습니다. 4개 트랙은 그 논리가 성립하는지, 깨졌는지를 평가합니다.

| | A. 추세반등 | B. 저평가 매수 |
|---|---|---|
| 매수 논리 | 상승 추세가 살아 있고 지금 하락은 일시적 눌림 | 가격이 가치보다 싸고, 가치가 훼손되고 있지 않음 |
| 진입 | 상대강도 상위 종목의 눌림 + 이익 추정치가 꺾이지 않음 | 매수선 도달 + 이익 추정치 안정·상향 |
| 손절 (논리가 틀렸을 때) | 눌림이 아니라 추세 전환으로 확인될 때 | 싼 이유가 생길 때(추정치 하향으로 적정가 하락, 킬 조건) |
| 매도 | 하락 추세 전환 | 고평가. 이익 추정치 상승에 따른 재평가면 보유 |

- 트랙의 역할: 기술은 타이밍과 추세 무효화 판정, 실적은 가치 함정과 재평가 판별, 가치는 진입 구간과 고평가 매도, 거시·국면 게이트는 진입 크기 조절(위험 온도계).
- **아직 설계 단계입니다.** 현재 앱의 종합 판정과 실행 레이더는 이전 방식(아래 '종합 탭' 설명, 기존 셋업 스캐너)으로 동작합니다. 틀 B는 과거 시점 데이터가 없어 검증하지 못했고, 앞으로 컨센서스·신호 기록을 쌓아 확인할 계획입니다. 자세한 내용과 작업 순서는 `AGENTS.md` 4번에 있습니다.
- 야후는 '지금'의 컨센서스만 주기 때문에, 2026-11-14부터 대표 종목의 컨센서스 EPS·목표가·추정치 수정 건수를 매일 받아 `data/snapshots/`에 쌓고 있습니다. 이 기록이 충분히 쌓이면 실적·가치 트랙을 과거 시점 기준으로 검증할 수 있습니다.

## 데이터 원칙

- **실제 데이터만 사용합니다.** 미국은 yfinance, 한국은 DART(재무제표)·yfinance(가격), 거시 변수는 FRED, 한국 국고채 금리는 한국은행 ECOS에서 받습니다.
- **못 받은 값은 추정하지 않고 "데이터 없음"으로 표시**하며, 그 값에 기대는 판정은 계산에서 뺍니다. 화면마다 데이터 출처·기준일·받지 못한 항목을 함께 보여줍니다.
- 데이터가 아닌 모델 가정(예: 시장 위험프리미엄 — Damodaran 2026년 1월 국가별 표)은 설정값 한 곳에 출처와 함께 둡니다.

## 실행

```bash
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

`.env` 파일(커밋 금지)에 아래 키를 넣으면 해당 데이터를 받습니다. 없으면 그 항목은 "데이터 없음"으로 표시됩니다.

```
DART_API_KEY=...   # 한국 재무제표 (opendart.fss.or.kr)
FRED_API_KEY=...   # 미국 금리·스프레드 등 (없으면 FRED 공개 CSV로 시도)
ECOS_API_KEY=...   # 한국 국고채 10년 (ecos.bok.or.kr)
```

데이터가 실제로 받아지는지는 점검 스크립트로 확인할 수 있습니다.

```bash
python check_earnings_data.py NVDA 005930.KS
python check_fundamental_data.py NVDA
python check_macro_data.py NVDA
python check_peer_data.py NVDA
```

코드를 고친 뒤에는 회귀 테스트로 예전에 고친 문제가 다시 생기지 않았는지 확인합니다. 가짜 데이터로 돌아가며 인터넷 연결이나 API 키가 필요 없습니다.

```bash
python tests/run_all.py          # 전체 (약 1~2분)
python tests/run_all.py --fast   # 화면 검사 제외
```

## 판정 규칙 백테스트

```bash
python run_backtest.py                # 미국·한국 국면 게이트 + T 셋업 (실제 야후 데이터, 수 분)
python run_backtest.py --skip-setups  # 게이트만
python run_backtest.py --variants     # 규칙 후보 비교만 (저장된 결과 사용, 1분 안팎) → data/backtest/VARIANTS.md
python run_backtest.py --setup-diag   # T 셋업 진단: 실제 신호 vs 무작위 진입 → data/backtest/SETUP_DIAG.md
python run_backtest.py --scanner      # 실제 T 스캐너 날짜별 재현 (ETF 19개, 2014년~, 몇 시간, 끊겨도 이어서) → SCANNER.md
python run_backtest.py --redesign     # T 트랙 재설계 후보(추세 추종·눌림목) 검증, 해외 국가 ETF로 판정 → REDESIGN.md
python run_backtest.py --frame-a      # 틀 A(추세반등) 개별 종목 검증, 새 종목 83개로 판정 (5~10분) → FRAME_A.md
```

- 국면 게이트를 2000년부터 날짜마다 앱과 같은 함수로 다시 계산합니다(그날 이전 데이터만 사용). 게이트 단계별 이후 지수 성과와, 게이트대로 노출을 줄인 전략을 매수 후 보유·같은 평균 노출 고정 비중과 비교합니다.
- T 셋업(ST-1·ST-2) 성과를 신호일의 게이트 단계별로 나눠 봅니다.
- 결과: `data/backtest/REPORT.md` (한계와 주의 사항 포함)

### 결과 요약 (2026-11-12 실행, 2001~2026년 일봉)

| 질문 | 미국 (SPY) | 한국 (KOSPI) |
|---|---|---|
| G3일 때 이후 20일 변동성이 G0보다 큰가 | 예 — 21.7% vs 11.6% (앞·뒤 기간 모두 1.7~2.0배) | 약함 — 21.7% vs 18.3% (뒤 기간 1.0배) |
| G3일 때 이후 수익률이 낮은가 | 아니오 — +0.7% vs +0.5% (차이가 오차 범위 안) | 아니오 — +0.8% vs +0.5% |
| 게이트대로 노출을 줄이면 같은 평균 노출의 고정 비중보다 나은가 | 아니오 — 샤프 0.38 vs 0.55 (비용 0이면 0.59 vs 0.55로 비슷), 최대 낙폭은 −10.6% vs −18.9%로 작음 | 아니오 — 샤프 0.21 vs 0.49 (비용 0이어도 0.33), 최대 낙폭도 −26.2% vs −17.9%로 큼 |
| G3가 켜진 기간 | 41% | 48% |
| G3의 주된 원인 | 지수가 200일 지수이동평균 아래(레짐 위기) 78%, 레짐 하나 때문 44% | 같은 패턴 82% · 53% |

- 해석: 국면 게이트는 **위험(변동성·큰 낙폭)이 커지는 시기를 구분하는 지표로는 의미가 있지만(특히 미국), 수익을 예측하거나 노출 타이밍을 맞추는 신호로는 확인되지 않았습니다.** 2000~2013년(닷컴·금융위기)에는 낙폭을 줄였고, 2014년 이후(빠른 V자 반등)에는 수익을 크게 놓쳤습니다.
- G3의 대부분은 '지수가 200일선 아래'라는 추세 조건 하나에서 나옵니다. VIX를 거시 국면으로 한 번 더 세는 경우(거시 국면만 G3)는 6~7%로 작았습니다.
- T 셋업(레이더 카드의 단순화 규칙, 83종목·9,088건): 생존 편향이 작은 ETF에서 기대값 −0.12R ±0.03(왕복 비용 0.30%), 미국 ETF는 비용 0%에서도 −0.03R로 우위가 없습니다. 게이트로 진입을 제한해도 거래당 기대값은 나아지지 않았습니다(−0.02R vs −0.01R). 과매도 반전형(ST-1) 신호의 81%가 G3에서 나와, 'G3 신규 매수 동결' 규칙과 서로 맞지 않습니다.
- 규칙 후보 비교 (2026-11-13, `data/backtest/VARIANTS.md`): 후보와 기준을 결과를 보기 전에 고정하고 앞 기간(2001~2013)으로 고른 뒤 뒤 기간(2014~2026)으로 확인했습니다. 200일선 이탈을 G2로 낮추는 안(A)과 '추세 붕괴 + 공포'가 겹칠 때만 G3로 하는 안(B)은 둘 다 앞 기간 G3 비중 기준(≤20%)을 넘어(A 24%·24%, B 미국 28%·한국 21%) **현재 규칙을 유지**합니다. 기준과 별개로도 두 안 모두 앞 기간 타이밍 효과가 현재보다 나빴습니다(미국 −0.06 vs +0.02). ST-1을 G2·G3에서 20% 허용하는 안도 ETF 합계 R을 앞 기간 −13.2R·뒤 기간 −5.2R 낮춰 채택하지 않습니다 — ST-1은 G3에서도 손실이라 현재의 진입 차단이 데이터와 맞습니다.
- 한국 게이트는 2014년 이후 G3의 위험 구분력이 없습니다(G3 변동성 ÷ G0·G1 = 0.91배).
- 한국 게이트 후보 C(미국 VIX·QQQ 대신 KOSPI 자체 변동성·레짐, 2026-11-13): 뒤 기간 위험 구분력은 0.91배 → 1.39배로 나아졌지만 G3 비중(45%, 주원인은 200일선 조건)이 기준을 넘어 채택하지 않았습니다. 뒤 기간을 여러 번 봤기 때문에 게이트 후보 비교는 여기서 멈추고, 앞으로 쌓이는 데이터로 확인합니다.
- T 셋업 진단(2026-11-13, `data/backtest/SETUP_DIAG.md`): 같은 매매 방식으로 아무 날에나 진입한 경우와 비교하면, ETF에서 ST-1은 −0.14R vs −0.11R(차이 없음), ST-2는 −0.10R vs −0.01R(오히려 나쁨)로 **두 셋업 모두 신호 조건의 우위가 확인되지 않았습니다.** 레이더 카드에 '장기 검증 미통과'를 표시합니다.
- 실제 셋업 스캐너 검증(2026-11-13, `data/backtest/SCANNER.md`): 섹터 ETF 19개에서 2014~2026년 매 거래일마다 앱 레이더와 같은 판정을 재현했습니다(57,171일). 진입 신호는 251건으로 드물었고, 평균 −0.15R로 같은 손절·목표 모양을 무작위 날짜에 적용한 결과(+0.06R)보다 낫지 않았습니다.
- 재설계 후보(2026-11-13, `data/backtest/REDESIGN.md`): 관행 매개변수를 그대로 쓴 두 후보를 처음 보는 해외 국가 ETF 18개로 판정했습니다. 추세 추종(55일 최고 돌파)은 미통과, **눌림목 반등(200일선 위 + RSI(2) < 10, 5일선 위 마감 청산)은 통과**했습니다(+0.01R vs 무작위 −0.06R, z +5.5, 승률 62%, 평균 3.7일 보유). 다만 왕복 비용 0.30%를 빼면 거래당 약 +0.10%라 비용에 민감하고 손절이 없는 규칙이어서, 단독 매매 신호가 아니라 '추세반등' 틀의 진입 조건으로 쓸 계획입니다.

```
utils.py                    공통 스타일·사이드바
check_*.py                  실제 데이터 수집 점검 스크립트

```

## 한계

- 판정 규칙(임계값·가중치)은 설계 문서에 근거한 값입니다. 백테스트 결과는 위 '결과 요약'과 같습니다: 국면 게이트는 위험 구분만 확인됐고, 기존 기술적 진입 신호는 우위가 확인되지 않았으며, 눌림목 반등 조건 하나만 작은 우위가 확인됐습니다. 실적·가치·거시 트랙과 '저평가 매수' 틀은 과거 시점 데이터가 없어 백테스트하지 않았습니다.
- 야후 파이낸스의 업종 분류에 의존하므로, 같은 산업에 비교할 만한 기업이 5곳 미만이면 피어 비교는 "데이터 없음"이 됩니다.
- 무료 공개 데이터라 지연·수정·누락이 있을 수 있습니다.

## 개발 방식

설계(트랙 구성, 판정 규칙, 데이터 원칙)와 검증은 직접 했고, 코드 작성·수정에는 AI 코딩 도구(Claude, Gemini)를 함께 사용했습니다. 작업 규칙과 변경 이력은 `AGENTS.md`에 남겨 두었습니다.
