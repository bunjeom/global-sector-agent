# 투자터미널 (global-sector-agent)

한 종목을 **네 가지 관점(기술·실적·가치·거시)** 으로 따로 분석한 뒤 하나의 결론으로 합치는 Streamlit 기반 종목 분석 도구입니다.
미국·한국 상장 종목을 지원하며, 모든 숫자는 공개 데이터에서 받아 계산합니다.

프로젝트 수업에서 시작한 뒤, 혼자 기능을 넓혀 가며 계속 개발하고 있습니다.

> 개인 학습·연구용 프로젝트이며 투자 권유가 아닙니다. 판정 규칙 중 국면 게이트와 T 셋업만 과거 가격으로 백테스트할 수 있으며(`run_backtest.py`), 실적·가치·거시 트랙은 과거 시점 데이터가 없어 검증하지 않았습니다.

## 무엇을 하나

| 트랙 | 질문 | 주요 계산 |
|---|---|---|
| T · 기술 | 지금 사고팔 시점인가 | 7단계 차트 상태, 지지·저항 구간, 셋업별 진입·손절·목표가와 1R 기준 수량 |
| E · 실적 | 이익이 어느 단계에 있나 | 실적 국면 G1~G5, 서프라이즈·리비전, 증분 영업이익률, 이익의 질 5개 점검 |
| V · 가치 | 얼마면 살 만한가 | 자기 PER 밴드(σ)·피어 PER, 국면별 목표 배수, 0~3차 분할 매수선, 시나리오 기대수익률 |
| 거시 | 거시 변수에 얼마나 흔들리나 | 시장 잔차화 회귀(HAC·Huber), 표본 외(OOS) 검증, 13주 수익률 기여 분해 |

종합 탭은 하드 킬 게이트 → V 가격 자격 → T 판정 → 거시 오버레이 순으로 결론을 내고, 8개 종목 유형(ARCH_1~8)과 3줄 요약으로 보여줍니다.

## 데이터 원칙

- **실제 데이터만 사용합니다.** 미국은 yfinance, 한국은 DART(재무제표)·yfinance(가격), 거시 변수는 FRED, 한국 국고채 금리는 한국은행 ECOS에서 받습니다.
- **못 받은 값은 추정하지 않고 "데이터 없음"으로 표시**하며, 그 값에 기대는 판정은 계산에서 뺍니다. 화면마다 데이터 출처·기준일·받지 못한 항목을 함께 보여줍니다.
- 데이터가 아닌 모델 가정(예: 시장 위험프리미엄 — Damodaran 2026년 1월 국가별 표)은 설정값 한 곳에 출처와 함께 둡니다.

## 실행

```bash
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

`.env` 파일(커밋 금지)에 아래 키를 넣으면 해당 데이터를 받습니다. 없으면 그 항목은 "데이터 없음"으로 표시됩니다.

```
DART_API_KEY=...   # 한국 재무제표 (opendart.fss.or.kr)
FRED_API_KEY=...   # 미국 금리·스프레드 등 (없으면 FRED 공개 CSV로 시도)
ECOS_API_KEY=...   # 한국 국고채 10년 (ecos.bok.or.kr)
```

데이터가 실제로 받아지는지는 점검 스크립트로 확인할 수 있습니다.

```bash
python check_earnings_data.py NVDA 005930.KS
python check_fundamental_data.py NVDA
python check_macro_data.py NVDA
python check_peer_data.py NVDA
```

코드를 고친 뒤에는 회귀 테스트로 예전에 고친 문제가 다시 생기지 않았는지 확인합니다. 가짜 데이터로 돌아가며 인터넷 연결이나 API 키가 필요 없습니다.

```bash
python tests/run_all.py          # 전체 (약 1~2분)
python tests/run_all.py --fast   # 화면 검사 제외
```

## 판정 규칙 백테스트

```bash
python run_backtest.py                # 미국·한국 국면 게이트 + T 셋업 (실제 야후 데이터, 수 분)
python run_backtest.py --skip-setups  # 게이트만
python run_backtest.py --variants     # 규칙 후보 비교만 (저장된 결과 사용, 1분 안팎) → data/backtest/VARIANTS.md
```

- 국면 게이트를 2000년부터 날짜마다 앱과 같은 함수로 다시 계산합니다(그날 이전 데이터만 사용). 게이트 단계별 이후 지수 성과와, 게이트대로 노출을 줄인 전략을 매수 후 보유·같은 평균 노출 고정 비중과 비교합니다.
- T 셋업(ST-1·ST-2) 성과를 신호일의 게이트 단계별로 나눠 봅니다.
- 결과: `data/backtest/REPORT.md` (한계와 주의 사항 포함)

### 결과 요약 (2026-11-12 실행, 2001~2026년 일봉)

| 질문 | 미국 (SPY) | 한국 (KOSPI) |
|---|---|---|
| G3일 때 이후 20일 변동성이 G0보다 큰가 | 예 — 21.7% vs 11.6% (앞·뒤 기간 모두 1.7~2.0배) | 약함 — 21.7% vs 18.3% (뒤 기간 1.0배) |
| G3일 때 이후 수익률이 낮은가 | 아니오 — +0.7% vs +0.5% (차이가 오차 범위 안) | 아니오 — +0.8% vs +0.5% |
| 게이트대로 노출을 줄이면 같은 평균 노출의 고정 비중보다 나은가 | 아니오 — 샤프 0.38 vs 0.55 (비용 0이면 0.59 vs 0.55로 비슷), 최대 낙폭은 −10.6% vs −18.9%로 작음 | 아니오 — 샤프 0.21 vs 0.49 (비용 0이어도 0.33), 최대 낙폭도 −26.2% vs −17.9%로 큼 |
| G3가 켜진 기간 | 41% | 48% |
| G3의 주된 원인 | 지수가 200일 지수이동평균 아래(레짐 위기) 78%, 레짐 하나 때문 44% | 같은 패턴 82% · 53% |

- 해석: 국면 게이트는 **위험(변동성·큰 낙폭)이 커지는 시기를 구분하는 지표로는 의미가 있지만(특히 미국), 수익을 예측하거나 노출 타이밍을 맞추는 신호로는 확인되지 않았습니다.** 2000~2013년(닷컴·금융위기)에는 낙폭을 줄였고, 2014년 이후(빠른 V자 반등)에는 수익을 크게 놓쳤습니다.
- G3의 대부분은 '지수가 200일선 아래'라는 추세 조건 하나에서 나옵니다. VIX를 거시 국면으로 한 번 더 세는 경우(거시 국면만 G3)는 6~7%로 작았습니다.
- T 셋업(레이더 카드의 단순화 규칙, 83종목·9,088건): 생존 편향이 작은 ETF에서 기대값 −0.12R ±0.03(왕복 비용 0.30%), 미국 ETF는 비용 0%에서도 −0.03R로 우위가 없습니다. 게이트로 진입을 제한해도 거래당 기대값은 나아지지 않았습니다(−0.02R vs −0.01R). 과매도 반전형(ST-1) 신호의 81%가 G3에서 나와, 'G3 신규 매수 동결' 규칙과 서로 맞지 않습니다.
- 판정 규칙은 아직 바꾸지 않았습니다. 바꿀 때는 앞 기간(2001~2013)으로 정하고 뒤 기간(2014~2026)으로 확인합니다. 다만 위 결과를 이미 전체 기간으로 봤기 때문에 이 확인도 완전히 독립적이지는 않습니다.

## 구조

```
app.py                      홈: 시장 국면, 섹터 흐름(RRG), 실행 레이더
pages/1_🔎_종목_딥다이브.py   종목 딥다이브 (종합 + 4개 트랙 탭)
engine/                     계산 엔진 패키지 (트랙별 분석·데이터 수집층·종합 판정·백테스트, 기능별 13개 모듈)
utils.py                    공통 스타일·사이드바
check_*.py                  실제 데이터 수집 점검 스크립트
run_backtest.py             판정 규칙 백테스트 실행 (결과 data/backtest/)
tests/                      회귀 테스트 (가짜 데이터·오프라인, run_all.py로 실행)
AGENTS.md                   설계 규칙과 변경 기록
```

## 한계

- 판정 규칙(임계값·가중치)은 설계 문서에 근거한 값입니다. 국면 게이트·T 셋업의 백테스트 결과는 위 '결과 요약'과 같으며(게이트는 위험 구분만 확인, T 셋업은 우위 미확인), 실적·가치·거시 트랙은 과거 시점 데이터가 없어 백테스트하지 않았습니다.
- 야후 파이낸스의 업종 분류에 의존하므로, 같은 산업에 비교할 만한 기업이 5곳 미만이면 피어 비교는 "데이터 없음"이 됩니다.
- 무료 공개 데이터라 지연·수정·누락이 있을 수 있습니다.

## 개발 방식

설계(트랙 구성, 판정 규칙, 데이터 원칙)와 검증은 직접 했고, 코드 작성·수정에는 AI 코딩 도구(Claude, Gemini)를 함께 사용했습니다. 작업 규칙과 변경 이력은 `AGENTS.md`에 남겨 두었습니다.
